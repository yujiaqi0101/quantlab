# Dataset 数据集格式要求

## 1. 概述 Overview

QuantLab 支持两种数据集管理入口：

| 入口 | API 前缀 | 用途 |
|------|---------|------|
| **Datasets 页面** | `/api/v1/datasets` | 行情数据浏览、预览、统计（只读，由系统扫描 `data/` 目录自动注册） |
| **ML Lab Dataset Center** | `/api/v1/ml/datasets` | 训练数据管理，支持创建数据集 + 上传 CSV |

---

## 2. 上传方式 Upload Methods

### 2.1 ML Lab 上传 CSV（推荐）

通过 ML Lab 的 Dataset Center 面板上传 CSV 文件：

**步骤：**

1. **创建数据集** — `POST /api/v1/ml/datasets`
   ```json
   {
     "name": "BTC_1h",
     "symbols": ["BTC"],
     "frequency": "1h",
     "description": "BTC/USDT 1小时K线",
     "tags": ["crypto", "BTC"]
   }
   ```

2. **上传 CSV 文件** — `POST /api/v1/ml/datasets/{dataset_id}/load_csv`
   - Content-Type: `multipart/form-data`
   - 字段名: `file`
   - 上传后系统自动解析并持久化到 Parquet

### 2.2 自动扫描 data/ 目录

系统启动时会自动扫描 `data/` 目录下的数据文件并注册到 DatasetRegistry。适合预置的行情数据。

### 2.3 编程方式加载

```python
from quantlab.ml.dataset import get_dataset_manager

mgr = get_dataset_manager()

# 创建数据集
ds = mgr.create_dataset(
    name="Crypto_1H",
    symbols=["BTC", "ETH", "SOL"],
    frequency="1h",
    description="加密货币1小时K线",
    tags=["crypto"],
)

# 从 CSV 文件加载
mgr.load_csv(ds.dataset_id, "data/btc_1h.csv")

# 或从 DataFrame 加载
import pandas as pd
df = pd.read_csv("data/btc_1h.csv", index_col=0, parse_dates=True)
mgr.load_dataframe(ds.dataset_id, df)
```

## 3. CSV 文件格式要求 CSV Format Requirements

### 3.1 基本要求

| 要求 | 说明 |
|------|------|
| **索引列** | 第一列必须为时间戳（Datetime），作为 `index_col=0` 解析 |
| **时间格式** | ISO 8601 格式，如 `2024-01-01 00:00:00` 或 `2024-01-01T00:00:00Z` |
| **编码** | UTF-8 |
| **分隔符** | 逗号 `,` |
| **缺失值** | 空单元格或 `NaN`，系统会自动统计缺失率 |

### 3.2 OHLCV 标准格式（行情数据）

行情数据建议包含以下标准列：

```
datetime,open,high,low,close,volume
2024-01-01 00:00:00,42000.5,42150.0,41900.0,42080.0,1234.56
2024-01-01 01:00:00,42080.0,42200.0,42050.0,42150.0,987.32
...
```

| 列名 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `open` | float | 推荐 | 开盘价 |
| `high` | float | 推荐 | 最高价 |
| `low` | float | 推荐 | 最低价 |
| `close` | float | **必填** | 收盘价 |
| `volume` | float | 推荐 | 成交量 |

### 3.3 特征数据格式（ML 训练）

用于 ML 模型训练的特征数据，列名可自定义：

```
datetime,rsi_14,momentum_20,atr_14,volatility,bollinger_upper,bollinger_lower
2024-01-01 00:00:00,65.2,0.032,450.5,0.18,42500.0,41500.0
2024-01-01 01:00:00,58.7,-0.015,448.2,0.17,42400.0,41600.0
...
```

### 3.4 多标的格式

多标的数据可通过以下方式组织：

**方式一：列名包含标的标识**
```
datetime,BTC_close,ETH_close,SOL_close,BTC_volume,ETH_volume,SOL_volume
2024-01-01 00:00:00,42080.0,2280.5,98.2,1234.56,890.12,567.89
...
```

**方式二：添加 symbol 列**
```
datetime,symbol,open,high,low,close,volume
2024-01-01 00:00:00,BTCUSDT,42000.5,42150.0,41900.0,42080.0,1234.56
2024-01-01 00:00:00,ETHUSDT,2270.0,2285.0,2265.0,2280.5,890.12
...
```

## 4. 支持的频率 Supported Frequencies

| 频率代码 | 说明 | 典型用途 |
|---------|------|---------|
| `1m` | 1分钟 | 高频策略、回放 |
| `5m` | 5分钟 | 日内策略 |
| `15m` | 15分钟 | 日内策略 |
| `1h` | 1小时 | 中频策略（推荐） |
| `4h` | 4小时 | 波段策略 |
| `1d` | 1天 | 中长期策略 |

---

## 5. 数据集元信息 Dataset Metadata

创建数据集时需提供以下信息：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `name` | string | **是** | — | 数据集名称，如 `BTC_1h` |
| `symbols` | string[] | 否 | `[]` | 标的列表，如 `["BTC", "ETH"]` |
| `frequency` | string | 否 | `"1d"` | 数据频率 |
| `description` | string | 否 | `""` | 数据集描述 |
| `tags` | string[] | 否 | `[]` | 标签，如 `["crypto", "BTC"]` |

## 6. 完整示例 Complete Example

### 6.1 CSV 文件示例（`btc_1h.csv`）

```csv
datetime,open,high,low,close,volume
2024-01-01 00:00:00,42000.50,42150.00,41900.00,42080.00,1234.56
2024-01-01 01:00:00,42080.00,42200.00,42050.00,42150.00,987.32
2024-01-01 02:00:00,42150.00,42300.00,42100.00,42250.00,1105.78
2024-01-01 03:00:00,42250.00,42400.00,42200.00,42350.00,1342.90
2024-01-01 04:00:00,42350.00,42500.00,42300.00,42450.00,876.45
```

### 6.2 上传流程

```bash
# 1. 创建数据集
curl -X POST http://localhost:8000/api/v1/ml/datasets \
  -H "Content-Type: application/json" \
  -d '{
    "name": "BTC_1h",
    "symbols": ["BTC"],
    "frequency": "1h",
    "description": "BTC/USDT 1小时K线数据",
    "tags": ["crypto", "BTC"]
  }'

# 返回结果中获取 dataset_id，例如 "DS-a1b2c3d4"

# 2. 上传 CSV
curl -X POST http://localhost:8000/api/v1/ml/datasets/DS-a1b2c3d4/load_csv \
  -F "file=@btc_1h.csv"
```

## 7. 数据存储 Data Storage

### 7.1 统一架构（已实现）

所有数据集通过 `DatasetManager` 统一管理，**单一数据源**：

```
                        ┌─────────────────────┐
                        │  storage/ml_lab.db   │  ← 唯一的元信息库
                        │  (SQLite, 统一表结构) │
                        └──────────┬──────────┘
                                   │
                    ┌──────────────┼──────────────┐
                    │              │              │
              ┌─────┴─────┐  ┌────┴─────┐  ┌────┴─────┐
              │ Datasets  │  │ ML Lab   │  │ 其他模块 │
              │ 页面 API  │  │ Dataset  │  │          │
              │           │  │ Center   │  │          │
              └───────────┘  └──────────┘  └──────────┘
                                   │
                        ┌──────────┴──────────┐
                        │ storage/parquet/     │  ← 唯一的数据存储
                        │ datasets/{id}.parquet│
                        └─────────────────────┘
```

| 存储类型 | 路径 | 说明 |
|---------|------|------|
| **SQLite** | `storage/ml_lab.db` | 数据集元信息（名称、频率、标签、asset_type、schema 等） |
| **Parquet** | `storage/parquet/datasets/{dataset_id}.parquet` | 实际数据，列式存储，高效压缩 |

系统启动时自动从 SQLite 恢复数据集元信息，并注入示例数据集（BTC_1h, ETH_1h 等）。
数据 DataFrame 按需从 Parquet 加载（懒加载机制）。

### 7.2 统一表结构

`ml_lab.db` 中的 `datasets` 表包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `dataset_id` | TEXT PK | 数据集 ID |
| `name` | TEXT | 数据集名称 |
| `symbols` | TEXT | 标的列表（JSON 或逗号分隔） |
| `frequency` | TEXT | 数据频率（1m/5m/15m/1h/4h/1d） |
| `start_date` | TEXT | 起始时间 |
| `end_date` | TEXT | 结束时间 |
| `description` | TEXT | 描述 |
| `row_count` | INTEGER | 行数 |
| `created_at` | TEXT | 创建时间 |
| `asset_type` | TEXT | 资产类型（crypto/stock/futures） |
| `storage_path` | TEXT | 存储路径 |
| `storage_format` | TEXT | 存储格式（parquet） |
| `schema_json` | TEXT | Schema JSON（列名、类型、角色） |
| `tags_json` | TEXT | 标签 JSON |
| `is_ohlcv` | INTEGER | 是否为 OHLCV 数据 |
| `coverage` | TEXT | 覆盖范围描述 |

## 8. 常见问题 FAQ

**Q: CSV 第一列不是时间怎么办？**
A: 系统使用 `pd.read_csv(filepath, index_col=0, parse_dates=True)` 解析，第一列必须为可解析的时间格式。如果第一列不是时间，上传会失败。

**Q: CSV 中可以有中文列名吗？**
A: 可以，但建议使用英文列名以兼容特征工程和模型训练流程。

**Q: 数据量很大怎么办？**
A: 系统使用 Parquet 列式存储，支持高效压缩和按需加载。大文件上传后自动转换为 Parquet 格式。

**Q: 如何查看数据集统计信息？**
A: 通过 API `GET /api/v1/ml/datasets/{id}/stats` 获取，包括行数、列数、缺失率、数据类型等。

**Q: 系统预置了哪些示例数据集？**
A: 系统启动时自动注册以下示例数据集（位于 Datasets 页面）：

| dataset_id | 名称 | 频率 | 标的 |
|-----------|------|------|------|
| BTC_1h | BTC/USDT 1H | 1h | BTCUSDT |
| ETH_1h | ETH/USDT 1H | 1h | ETHUSDT |
| SOL_4h | SOL/USDT 4H | 4h | SOLUSDT |
| BNB_1d | BNB/USDT 1D | 1d | BNBUSDT |
| BTC_5m | BTC/USDT 5M | 5m | BTCUSDT |
| ETH_15m | ETH/USDT 15M | 15m | ETHUSDT |
| MULTI_1h | Multi-Crypto 1H | 1h | BTCUSDT,ETHUSDT,SOLUSDT |
